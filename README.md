food-stock-app

概要

食材の在庫管理を中心としたWebアプリケーションです。

食材の登録・編集・削除、在庫数量の更新、検索・絞り込み・並び替え、重複登録時の確認、消費期限管理、買うものリストなど、日常的な在庫管理に必要な機能を段階的に実装しています。

まずは、機械学習や外部APIに依存せず、単一ユーザーが在庫管理アプリとして利用できる状態を完成させます。

その後、レシピ管理、在庫とレシピの照合、レシートOCR、外部APIやAIを活用したレシピ提案などを追加し、食材の登録から消費までを支援するアプリケーションへ発展させる予定です。

家計簿機能は実装対象とせず、食材在庫の管理と有効活用に機能を集中させます。

開発目的

日常生活では、現在の食材在庫を正確に把握できず、次のような問題が発生することがあります。

必要な食材を買い忘れる

同じ食材を重複して購入する

消費期限を把握できず、食材を廃棄する

現在の在庫を献立に活用できない

本アプリでは、食材の在庫を簡単に登録・確認・更新できる仕組みを作ることで、買い忘れ、重複購入、食品ロスの削減を目指します。

ローカルでの起動方法

1. リポジトリをクローンする

git clone git@github.com:yuzuan419656/food-stock-app.git
cd food-stock-app

2. 仮想環境を作成する

python -m venv .venv

3. 仮想環境を有効化する

WSL / Linux / macOS：

source .venv/bin/activate

Windows PowerShell：

.venv\Scripts\Activate.ps1

4. ライブラリをインストールする

pip install -r requirements.txt

5. マイグレーションを適用する

alembic upgrade head

6. アプリケーションを起動する

uvicorn app.main:app --reload

7. ブラウザで確認する

http://127.0.0.1:8000

FastAPIの自動生成ドキュメント：

http://127.0.0.1:8000/docs
