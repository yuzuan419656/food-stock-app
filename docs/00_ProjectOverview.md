# Project Overview

## 1. プロジェクト概要

レシートOCRを利用した食材管理・レシピ提案Webアプリケーション。

レシート画像から購入した食材を自動で登録し、現在の在庫状況を管理する。また、在庫情報をもとに作成可能なレシピや、不足している食材を含めたレシピを提案することで、日々の献立決定を支援する。

---

## 2. 開発背景・目的

毎日の献立を考えることは手間がかかるだけでなく、冷蔵庫の中身を正確に把握できず、同じ食材を重複して購入したり、使い切れずに廃棄してしまうことがある。

本プロジェクトでは、レシートOCRによる食材登録の自動化と在庫管理を行い、現在の在庫状況から最適なレシピを提案することで、献立決定の負担軽減と食品ロスの削減を目指す。

また、本プロジェクトはPython・FastAPI・データベース設計・API連携・AWSなどの技術を学習・実践することも目的とする。

## 6. システム概要

本システムはブラウザ上で利用するWebアプリケーションとして開発する。

利用者は食材を手動で登録する。

↓

在庫を管理する。

↓

在庫を確認する。

下記機能も追加予定。

将来的にはレシート画像からの購入品情報の読み取り。

登録された在庫情報をもとに、

- 現在の在庫だけで作れるレシピ
- 少数の食材を追加するだけで作れるレシピ

を表示する。

レシピを選択して調理した場合は、使用した食材を在庫から自動的に減算し、調理履歴として保存する。

- 小さく作り、小さく改善する
- 実際に自分が使える品質を目指す
