# Project Overview

## 1. プロジェクト概要

食材在庫管理を中心としたWebアプリケーション。

まずは食材の登録・編集・削除・在庫管理を行えるシステムを開発する。
その後、レシートOCR・レシピ提案・家計簿などの機能を段階的に追加し、
日々の食材管理を支援するアプリケーションへ発展させる。

---

## 2. 開発背景・目的

日常生活では、現在の在庫を正確に把握できず、
同じ食材を重複して購入したり、使い切れず廃棄してしまうことがある。

本プロジェクトでは、まず食材の在庫を簡単に管理できるWebアプリを開発する。

その後、OCRによる登録自動化やレシピ提案などを追加することで、
献立決定の負担軽減と食品ロス削減を目指す。

また、本プロジェクトを通して、

- Python
- FastAPI
- SQLAlchemy
- データベース設計
- Git / GitHub

などのバックエンド開発技術を習得することも目的とする。

## 6. システム概要

本システムはブラウザ上で利用するWebアプリケーションとして開発する。

利用者は食材を登録・編集・削除し、
現在の在庫を一覧で確認できる。

在庫情報はデータベースへ保存され、
いつでも最新の在庫状況を確認できる。

将来的には、

- レシートOCR
- レシピ提案
- 調理履歴
- 家計簿

などの機能を追加し、
食材管理を総合的に支援するアプリへ発展させる。
