# Requirements

## はじめに

本書では、Phase1（MVP）の要件を定義する。

本システムは、食材在庫管理Webアプリケーションである。

---

# 1. システム要件

- Webブラウザから利用できること
- ローカル環境で動作すること
- 食材情報を永続化できること

---

# 2. 機能要件

## 2.1 食材マスタ

### 要件

- 食材を登録できる
- 食材を編集できる
- 食材を削除できる
- 食材を検索できる

---

## 2.2 在庫管理

### 要件

- 食材の在庫数量を管理できる
- 在庫を追加できる
- 在庫を減らせる
- 在庫一覧を表示できる

---

# 3. 非機能要件

## 開発環境

- Python
- FastAPI
- SQLAlchemy
- SQLite
- Git
- GitHub

## 品質

- 拡張しやすい構成とする
- 可読性を重視する
- 保守しやすい構成とする

---
