## 4. S001 食材一覧画面

### URL

```text
/
```

### 表示内容

- 食材名検索
- 並び替え
- 在庫なしを先頭
- カテゴリ複数選択フィルター
- 食材名
- カテゴリ
- 在庫数量
- 消費期限入力欄
- 単位
- 編集・削除
- Step10で追加する買うものリスト選択チェックボックス
- Step10で追加する「選択した食材を買うものリストに追加」ボタン

### 消費期限の操作

- 日付入力欄は常時表示する
- 手入力またはカレンダーで日付を選択できる
- 日付確定時に非同期で自動保存する
- 保存中は「保存中…」を表示する
- 成功時は「保存しました」を一時表示する
- 失敗時は元の値へ戻してエラーを表示する
- 保存時にページ全体を再読み込みしない

### 並び替え

- カテゴリ順
- 食材名順
- 登録順
- 消費期限が近い順
- 消費期限が遠い順

期限未設定は期限順の最後へ表示する。

## 8. S006 買うものリスト画面（Step10）

### URL

```text
/shopping-list
```

### 表示内容

| 項目 | 内容 |
|---|---|
| 食材名 | 対象の食材 |
| カテゴリ | 食材カテゴリ |
| 単位 | 基本単位 |
| 状態 | 未購入／購入済み |
| 状態変更 | 購入済み・未購入を切り替える |
| 削除 | リストから削除する |

### 操作方針

- 未購入を上に表示する
- 購入済みは視覚的に区別する
- 購入済みへ変更しても在庫数量は増やさない
- 同じ食材を重複表示しない
- 在庫一覧へ戻るリンクを表示する

---

## 9. Step10ルーティング予定

| Method | URL | 処理 |
|---|---|---|
| GET | `/shopping-list` | 一覧表示 |
| POST | `/shopping-list` | 複数食材追加 |
| POST | `/shopping-list/{id}/toggle` | 購入状態切替 |
| POST | `/shopping-list/{id}/delete` | 項目削除 |
