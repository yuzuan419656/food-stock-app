## 4. S001 食材一覧画面

### URL

```text
/
```

### 表示内容

- 食材名検索
- 並び替え
- 在庫なしを先頭
- カテゴリ複数選択フィルター
- 買うものリスト選択チェックボックス
- 食材名
- カテゴリ
- 在庫数量
- 購入日入力欄
- 消費期限入力欄
- 単位
- 編集・削除
- 「選択した食材を買うものリストに追加」ボタン
- 買うものリスト画面へのリンク

### 購入日の操作

- 日付入力欄は常時表示する
- 手入力またはカレンダーで日付を選択できる
- 日付確定時に非同期で自動保存する
- 購入日は必須とする
- 空欄にした場合は元の値へ戻す
- 保存中は「保存中…」を表示する
- 成功時は「保存しました」を一時表示する
- 失敗時は元の値へ戻してエラーを表示する
- 保存時にページ全体を再読み込みしない

### 消費期限の操作

- 日付入力欄は常時表示する
- 手入力またはカレンダーで日付を選択できる
- 日付確定時に非同期で自動保存する
- 日付を空欄にすると未設定へ戻す
- 保存中は「保存中…」を表示する
- 成功時は「保存しました」を一時表示する
- 失敗時は元の値へ戻してエラーを表示する
- 保存時にページ全体を再読み込みしない

### 並び替え

- カテゴリ順
- 食材名順
- 登録順
- 消費期限が近い順
- 消費期限が遠い順

期限未設定は期限順の最後へ表示する。

## 8. S005 重複食材・復元確認画面

### 表示内容

- 既存食材の状態
- 既存の食材情報
- 既存ロットの合計数量
- 既存ロットの代表購入日
- 既存ロットの代表消費期限
- 今回入力した食材情報
- 今回入力した数量
- 今回入力した購入日
- 今回入力した消費期限

### 有効な同名食材の場合

- 今回の数量を新しい在庫ロットとして追加
- 既存データを今回の内容で上書き
- 登録をキャンセル

### 削除済みの同名食材の場合

- 削除済み食材を復元
- 登録をキャンセル

復元時は以前の在庫ロットを保持し、今回の数量が0より大きい場合は新しいロットとして追加する。

既存の基本単位と今回の基本単位が異なる場合は復元できない。

## 9. S006 買うものリスト画面

| S007 | 買うもの追加 | `/shopping-list/add` | 実装済み |
| S008 | 削除済み食材復元確認 | 登録処理内 | 実装済み |

### URL

```text
/shopping-list
```

### 表示内容

| 項目 | 内容 |
|---|---|
| 食材名 | 対象の食材 |
| カテゴリ | 食材カテゴリ |
| 単位 | 基本単位 |
| 状態 | 未購入／購入済み |
| 状態変更 | 購入済み・未購入を切り替える |
| 削除 | リストから個別削除する |

### 操作方針

- 未購入を上に表示する
- 購入済みは視覚的に区別する
- 購入済みへ変更しても在庫数量は増やさない
- 同じ食材を重複表示しない
- 購入済み項目を一括削除できる
- 在庫一覧へ戻るリンクを表示する

## 10. ルーティング

### 食材・在庫

| Method | URL | 処理 |
|---|---|---|
| GET | `/` | 在庫一覧表示 |
| GET | `/ingredients/new` | 食材登録画面 |
| POST | `/ingredients` | 食材登録 |
| GET | `/ingredients/{id}/edit` | 食材編集画面 |
| POST | `/ingredients/{id}/edit` | 食材更新 |
| GET | `/ingredients/{id}/delete` | 食材削除確認 |
| POST | `/ingredients/{id}/delete` | 食材削除 |
| POST | `/ingredients/{id}/purchase-date/auto` | 購入日の自動保存 |
| POST | `/ingredients/{id}/expiration-date/auto` | 消費期限の自動保存 |

### 買うものリスト

| Method | URL | 処理 |
|---|---|---|
| GET | `/shopping-list` | 一覧表示 |
| POST | `/shopping-list` | 複数食材追加 |
| POST | `/shopping-list/{id}/toggle` | 購入状態切替 |
| POST | `/shopping-list/{id}/delete` | 項目削除 |
| POST | `/shopping-list/delete-purchased` | 購入済み項目の一括削除 |
